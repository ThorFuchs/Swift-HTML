## Source identity and distribution

- Release source is the full SwiftPM repository tree, **not** a separate copy of
  SwiftSoup's upstream tests or webpage fixtures.
- Backend provenance: [SwiftSoup 2.14.4](https://github.com/scinfu/SwiftSoup/tree/8397a860c6955924b584c50c5265c6aac0970015)
  at commit `8397a860c6955924b584c50c5265c6aac0970015`,
  original Sources tree `f8472ba94c5dd20e84cc531ff046e7ad1029cdfa`.
- [UPSTREAM.json](../../Vendor/SwiftSoup/UPSTREAM.json) pins original
  file SHA-256 values and both transformations: namespace change in four files
  and the exact, reversible WASI `Mutex.swift`/`NSLock` shim.
- `python3 Scripts/verify-upstream.py` checks file inventory and reverses
  the modifications before comparing the original SHA-256 values.
  `--reference /path/to/scinfu-SwiftSoup` optionally compares pinned Git bytes.
- `python3 Scripts/verify-notices.py` verifies the packaged SwiftSoup/jsoup and
  LRUCache MIT resource texts against vendored source notices. SwiftHTML's own
  code uses Apache-2.0.
- The synthetic versioned-consumer gate creates tag `0.0.1` **only in a
  disposable local bare repository**; it tests SwiftPM version resolution,
  building and bundled MIT notices. This does **not** create or exercise the
  public 0.2.0 GitHub tag.
- SwiftPM root package declares no additional external package dependencies.
- A separately packaged static library, app or container must be audited for
  notice redistribution separately. No legal opinion is asserted.

## Reproduction — native Linux

~~~sh
swift --version  # Swift 6.4.2 for qualified baseline
python3 Scripts/verify-upstream.py
python3 Scripts/verify-notices.py
swift test -j 4
swift build -c release -j 2
swift test -c release -j 2
swift run --package-path Examples/Consumer -c release -j 2
python3 Scripts/test-versioned-consumer.py "$(git rev-parse HEAD)"
~~~

The GitHub workflow executes this sequence in the official pinned Swift 6.4.2
Ubuntu 24.04 image. The optimized build runs without the previous
`-no-whole-module-optimization` workaround.

## Reproduction — macOS 15 Intel

~~~sh
swift --version  # Apple Swift 6.4.2 (installed standalone toolchain)
swift test -j 4
swift build -c release -j 4
swift run --package-path Examples/DeploymentConsumer DeploymentConsumer
python3 Scripts/test-versioned-consumer.py "$(git rev-parse HEAD)"
~~~

Use an Xcode installation supplying a macOS 15 SDK, with Swift 6.4.2 installed
and actually selected. The workflow checks the backend compiler target is
`x86_64-apple-macos15.0`. Native tests and real consumer were executed on an
Intel GitHub macOS 15 runner.

~~~sh

  https://download.swift.org/swift-6.4.2-release/wasm-sdk/swift-6.4.2-RELEASE/swift-6.4.2-RELEASE_wasm.artifactbundle.tar.gz \
  --checksum 83baca83553f8c443cda7b84800912e6e709c3acd2e7ebf277794ca5836c0da5
~~~

WASI consumer smoke, **not** browser or all-host certification.
